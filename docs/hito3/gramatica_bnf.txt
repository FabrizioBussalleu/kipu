G0. Estructura general del programa
    programa → listaSentencias EOF
    listaSentencias → sentencia listaSentencias | ε
    sentencia → declaracion | asignacion | seleccion | iteracion | regla | retorno | entradaSalida | llamadaSentencia | bloque
    bloque → LLAVE_IZQ listaSentencias LLAVE_DER
G1. Declaración de variables y constantes
    declaracion → VAR ID DOS_PUNTOS tipo inicializacion PUNTO_COMA | CONST ID DOS_PUNTOS tipo ASIG expresion PUNTO_COMA
    inicializacion → ASIG expresion | ε
    tipo → ENTERO | DECIMAL | PORCENTAJE | BOOLEANO | TEXTO | MONTO MENOR MONEDA MAYOR
G2. Asignación
    asignacion → ID opAsignacion expresion PUNTO_COMA
    opAsignacion → ASIG | MAS_ASIG | MENOS_ASIG
G3. Expresiones
    expresion → expresion O conjuncion | conjuncion
    conjuncion → conjuncion Y negacion | negacion
    negacion → NO negacion | igualdad
    igualdad → igualdad IGUAL relacional | igualdad DIFERENTE relacional | relacional
    relacional → relacional MENOR aritmetica | relacional MENOR_IGUAL aritmetica | relacional MAYOR aritmetica | relacional MAYOR_IGUAL aritmetica | aritmetica
    aritmetica → aritmetica SUMA termino | aritmetica RESTA termino | termino
    termino → termino MULT unario | termino DIV unario | termino MOD unario | unario
    unario → RESTA unario | primario
    primario → PAR_IZQ expresion PAR_DER | CONVERTIR PAR_IZQ expresion COMA MONEDA COMA expresion PAR_DER | llamada | literal | ID
    literal → numero MONEDA | NUM_ENTERO | NUM_DECIMAL | LIT_PORCENTAJE | CADENA | VERDADERO | FALSO
    numero → NUM_ENTERO | NUM_DECIMAL
    llamada → ID PAR_IZQ argumentos PAR_DER
    argumentos → expresion argumentosCola | ε
    argumentosCola → COMA expresion argumentosCola | ε
G4. Sentencias selectivas
    seleccion → SI PAR_IZQ expresion PAR_DER bloque parteSino
    parteSino → SINO colaSino | ε
    colaSino → seleccion | bloque
G5. Sentencias iterativas
    iteracion → MIENTRAS PAR_IZQ expresion PAR_DER bloque | PARA ID DESDE expresion HASTA expresion pasoOpcional bloque
    pasoOpcional → PASO expresion | ε
G6. Reglas (funciones), retorno y llamadas
    regla → REGLA ID PAR_IZQ parametros PAR_DER tipoRetorno bloque
    parametros → parametro parametrosCola | ε
    parametrosCola → COMA parametro parametrosCola | ε
    parametro → ID DOS_PUNTOS tipo
    tipoRetorno → DOS_PUNTOS tipo | ε
    retorno → RETORNAR valorRetorno PUNTO_COMA
    valorRetorno → expresion | ε
    llamadaSentencia → llamada PUNTO_COMA
G7. Entrada y salida
    entradaSalida → MOSTRAR PAR_IZQ expresion argumentosCola PAR_DER PUNTO_COMA | LEER PAR_IZQ ID PAR_DER PUNTO_COMA
